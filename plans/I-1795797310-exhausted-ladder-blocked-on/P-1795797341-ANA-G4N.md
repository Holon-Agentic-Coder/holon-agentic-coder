  - If `uv run task lint` reports formatting issues, run `uv run task format` and re-verify with `uv run task lint`.
  - If any line budget is exceeded, refactor helper logic within the touched modules rather than touching
    `module_budgets.json`.

### Success & Discard Criteria

- **Success:** Affected tests, `uv run task test`, and `uv run task lint` all exit 0 in the foreground with zero
  modifications outside the Touch Set.
- **Discard:** Halt and diagnose if an unrelated failure appears in `uv run task test` or if verification cost exceeds
  `1.5x cost_pred`.
