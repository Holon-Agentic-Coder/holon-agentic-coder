## Plan Description & Strategy

Stage 5 must never write the stub report "Fallback calibration generated." When `run_calibrate` raises, the stage
retries transient errors a bounded number of times. Otherwise it fails closed with `StageStatus.FAILED`: no report, no
commit, no push, an empty `/calibrated` branch discarded, the checkpoint left at `CALIBRATE`, and a redacted cause in
the run summary. The failure ACT-CAL row is still appended to the ledger.
