   comments, matching the convention the old files used; type-annotated public functions).
2. Public API, named in the domain language of the intent:
   - `find_docstrings_and_string_statements(source) -> list[tuple[int, str]]`: walk `ast.parse(source)`; report
     module/class/function/async-function docstrings (via `ast.get_docstring(node, clean=False)`) and every standalone
     string-constant `ast.Expr` in any statement list (`body`, `orelse`, `finalbody`, and handler bodies), deduplicated

     allowlisted.

     encoding cookie (`^#.*?coding[:=]\s*[-\w.]+`) only on lines 1-2; full-line matches of `noqa` (optional `: codes`,
     case-insensitive), `type: ignore` (optional `[codes]`), `pragma: no cover` (case-insensitive).
   - `count_lines(source) -> int` using `len(source.splitlines())`, the same measure the old baseline tests used.
3. Keep each function under the ruff complexity limits (`C901 <= 10`, `PLR0912 <= 12`) by splitting the string-statement
   walk into a small helper over statement-list attributes; add no `# noqa`.
