2. Implement an AST inspector that walks `ast.Module`, `ast.ClassDef`, `ast.FunctionDef`, and `ast.AsyncFunctionDef`

   - Shebang on line 1, column 0 (`#!...`).

     `# pragma: no cover`.
4. Add test cases verifying:
   - `preflight.py` exists.
   - `preflight.py` has zero docstrings and zero standalone string literal statements.
   - `preflight.py` has zero non-allowlisted comments.
   - The inspector allows valid shebangs, encoding cookies, `# noqa`, `# type: ignore`, and `# pragma: no cover`.
   - The inspector rejects module/class/function/async-function docstrings and standalone string literal statements.
   - The inspector rejects plain explanatory comments, Sphinx `#:` comments, misplaced shebang/encoding lines, and prose
     mentioning pragma keywords.
5. Keep the test file completely hermetic (no network, no subprocesses, no external state) and compliant with ruff lint
   and format rules.
