- Create `apps/sandbox-executor/tests/test_self_doc_tests_45.py`:
  - It has no docstring and no comments of its own, and imports only `ast`, `io`, `re`, `tokenize`, `pathlib.Path` and
    `pytest`.
  - It must not import `tests.self_doc_scanner` and must not change any shared helper or `conftest.py`.
- Define `TESTS_DIR` as `Path(__file__).resolve().parent`.
- Define a constant `CLEANED_TEST_FILES` that lists the 12 scope paths relative to `TESTS_DIR`, in the order the intent
  gives them: `test_uv_lock.py`, …, `cli/test_intent_check_cli.py`.
- Define the allowed-comment rules as small named functions, each kept within ruff complexity limits:
  - `is_why_comment(text)`: the comment starts with `# why:`.
  - `is_shebang(line_number, text)`: line 1 and the text starts with `#!`.
  - `is_encoding_line(line_number, text)`: line 1 or 2 and the text matches the PEP 263 cookie regex `coding[:=]`.
  - `is_tool_directive(text)`: matches `#\s*(noqa|type:|pragma|fmt:)` at the start, or a trailing directive after other
    text, so that `# noqa: E501` and `# type: ignore[...]` both pass.
  - `is_permitted_comment(...)`: true if any of the four functions above is true.
- `find_docstrings(source)`: parse the source with `ast.parse`, walk every Module, ClassDef, FunctionDef and
  AsyncFunctionDef node, and report `(lineno, first line)` for each node where `ast.get_docstring(node, clean=False)` is
  not None.
- `find_disallowed_comments(source)`: read `tokenize.generate_tokens(io.StringIO(source).readline)`, keep COMMENT tokens
  that are not permitted, and report `(row, text)`. Because this uses tokenize, a `#` inside a string literal is never
  counted. `#:` attribute comments are counted, because they are not permitted.
- Write three tests, each parametrised over `CLEANED_TEST_FILES` with `pytest.param(path, id=path)`:
  - `test_cleaned_test_file_exists`
  - `test_cleaned_test_file_has_no_docstrings`, which asserts the findings list is empty and puts the path and findings
    in the failure message.
  - `test_cleaned_test_file_has_only_permitted_comments`, the same check for comments.
- Add two scanner self-tests on inline source strings, so the acceptance test cannot pass by finding nothing:
  - `test_scanner_reports_docstrings_and_plain_comments`: a module docstring, a function docstring and a `# plain`
    comment give 2 docstring findings and 1 comment finding.
  - `test_scanner_permits_why_shebang_encoding_and_directives`: a shebang, a coding line, a `# why:` comment, a trailing
    `# noqa: E501`, `# type: ignore`, `# pragma: no cover` and `# fmt: off` give zero findings, and a `"#"` inside a
    string literal gives zero findings.
- Run `uv run pytest apps/sandbox-executor/tests/test_self_doc_tests_45.py` in the foreground. The two self-tests and
  the 12 existence checks pass. The 24 scan checks fail, with 12 files reporting findings that add up to 92, which
  confirms the scanner matches the Step 1 baseline.
