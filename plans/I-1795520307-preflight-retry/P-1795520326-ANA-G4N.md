   - Combine captured output as `partial = _decode(exc.stdout) + _decode(exc.stderr)`.
   - If `_EXPECTED_REPLY_RE.search(partial)` matches:
     - Log a warning via `logger.warning` recording that the pre-flight probe for `target.agent` (`target.model`)

       `_result(PreflightStatus.OK, target.agent, target.model, target.image, exit_code=None, output=partial, hint=...)`

       `{target.limit:g}s` (slow exit) and does not suggest interactive login.

     (`QUOTA_EXHAUSTED`, `NOT_LOGGED_IN`, or `EXPIRED_KEY`), return
     `_result(classified, target.agent, target.model, target.image, exit_code=None, output=partial)` so clear auth/quota
     errors captured before timeout are preserved and not retried.
   - Otherwise, if `partial.strip()` is non-empty:
     - Return
       `_result(PreflightStatus.UNKNOWN, target.agent, target.model, target.image, exit_code=None, output=partial, hint=...)`
       with a hint that clearly names the timeout (`{target.limit:g}s`), notes that output was captured before timeout,
       advises inspecting the output or raising `HOLON_PREFLIGHT_TIMEOUT`, and does not suggest interactive login.
   - Otherwise (no captured output):
     - Return
       `_result(PreflightStatus.UNKNOWN, target.agent, target.model, target.image, exit_code=None, output=partial, hint=...)`
       naming the timeout (`{target.limit:g}s`) and retaining the interactive-login guidance for silent hangs
       (preserving compatibility with existing empty-output timeout tests).
3. Update `_run_probe` to delegate `subprocess.TimeoutExpired` to `_handle_probe_timeout` while keeping normal

   - `DEFAULT_MAX_ATTEMPTS = 3`
   - `DEFAULT_RETRY_DELAY_SECONDS = 2.0`
   - `_MODEL_ERROR_RE`: compiled case-insensitive regex matching clear deterministic model errors (such as
     `invalid model`, `unknown model`, `unsupported model`, `no such model`, `model_not_found`, `invalid_model`, and
     `model ... (not found|does not exist)`).
2. Add a private helper `_is_retryable_unknown(result: PreflightResult) -> bool` that returns `True` only when
   `result.status is PreflightStatus.UNKNOWN` and `_MODEL_ERROR_RE.search(result.output_excerpt)` is `None`. Clear
   auth/quota statuses (`NOT_LOGGED_IN`, `EXPIRED_KEY`, `QUOTA_EXHAUSTED`) and clear model errors return `False`.
3. Add a private helper `_with_container_name(docker_cmd: list[str], container_name: str) -> list[str]` that returns a
   copy of `docker_cmd` with the `--name` argument updated to `container_name`, so each retry attempt launches a
   container with a fresh unique `holon-preflight-<uuid>` name and avoids Docker name collisions.
4. Add a private helper `_run_probe_with_retries(run, docker_cmd, target, max_attempts)` that:
   - Clamps `attempts = max(1, max_attempts)`.
   - Loops `attempt` from `1` to `attempts`:
     - Generates `container_name = f"holon-preflight-{uuid.uuid4().hex[:12]}"` (or reuses the initial name on attempt 1
       and generates fresh names on retries) and builds
       `attempt_cmd = _with_container_name(docker_cmd, container_name)`.
     - Calls `_run_probe(run, attempt_cmd, container_name, target)`.
     - Returns immediately if `not _is_retryable_unknown(result)` or `attempt == attempts`.
     - Logs a warning noting transient `UNKNOWN` on attempt `attempt`/`attempts` and that the probe will retry after
       `DEFAULT_RETRY_DELAY_SECONDS`.
     - Calls `time.sleep(DEFAULT_RETRY_DELAY_SECONDS)` when `DEFAULT_RETRY_DELAY_SECONDS > 0`.
   - Returns the final `PreflightResult` (failing closed when retries are exhausted).
5. Update `run_preflight_probe` to accept an optional `max_attempts: int = DEFAULT_MAX_ATTEMPTS` parameter (keeping
   total parameters at 5, within `PLR0913 <= 5`), update its docstring, and invoke `_run_probe_with_retries` inside the
   existing `try ... finally` block so the `--env-file` is still created once and always deleted after the final
   attempt.
