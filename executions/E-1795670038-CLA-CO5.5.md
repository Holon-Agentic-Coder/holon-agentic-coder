# Execution Record: E-1795670038-CLA-CO5.5

## Summary

Implements plan `P-1795669298-CLA-CO5.5` for intent `I-1795669275-macos-unit-sensitive-paths-only`: the
`unit (macos-latest)` leg runs its expensive steps on a pull request only when a changed file is platform-sensitive by
path or by content (new or old version); otherwise the relevance gate step skips them and the job still succeeds under
its check name.

Outcome: everything is implemented and verified locally (lint, docs check of the touched files, 8280 tests). The replay
over the 62 pull requests merged into `main` from #241 to #314 shows the rule as the intent states it would have skipped
the macOS leg on only 1 of them (`1.6%`): flow code and its tests use `subprocess`, `Path.resolve`, `shutil` and
`tempfile` almost everywhere. The macOS leg's time on this pull request's own CI run is not in this record yet: CI
starts only after the entrypoint pushes this branch and opens the pull request.
