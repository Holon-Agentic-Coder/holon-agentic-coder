### Strategy Rationale

Three facts found during planning shape the strategy:

1. **The complexity identity snapshot is keyed by path.** `tests/test_complexity_gate.py` freezes the exact multiset of
   `(path, rule codes)` complexity `noqa` annotations and rejects any entry not in the snapshot; removals are allowed.
   `executor.py` carries five: `prepare_agent_output_block` (C901, measured 11), `run_cmd` (C901, 11),
   `_repair_git_repo` (C901, 12), `build_execution_prompt` (PLR0913, 6 args) and `main` (C901/PLR0912/PLR0915). Moving
   any of them into `executor/*.py` with its `noqa` creates a new snapshot entry and fails the gate. So all five must be
   made compliant, and that must happen **before or together with** the package move. Doing it first, while the code is
   still one module, keeps every `patch("sandbox_executor.entrypoint.executor.X")` target valid and lets the existing
   tests guard the logic change in isolation.
2. **Tests patch names on the module object.** About 90 `patch`/`monkeypatch.setattr` targets across `conftest.py`,
   `test_executor.py`, `test_executor_plan_decision.py`, `test_host_worktree_sandbox.py`, `test_ledger_append_only.py`,
   `test_resume_tip.py`, `test_pre_push_sync_conflict.py` and others replace `run_cmd`, `get_runner`,
   `validate_mounted_workspace`, `get_workspace_dir`, `workspace_mounted`, `sync_and_reconcile_pre_push`,
   `measure_executor_tests`, `run_turn`, `record_budget_failure`, `append_action_record`, `converge_prettier`,
   `prepare_agent_output_block` and `_get_local_safe_directories` on `sandbox_executor.entrypoint.executor`. Once the
   code lives in `executor/run.py`, a name imported with `from x import y` is no longer affected by patching the package
   attribute. The package must therefore resolve these collaborators through the package namespace at call time (a
   facade seam), so no out-of-scope test has to change its patch targets.
3. **`python -m` on a package needs `__main__.py`.** `role_dispatcher.sh` runs
   `python3 -m sandbox_executor.entrypoint.executor`. The intent's scope list omits `executor/__main__.py`, but without
   it the dispatcher fails with "is a package and cannot be directly executed". It is added to the touch set. Also,
   `tests/test_entrypoint_imports.py` globs `entrypoint/*.py` non-recursively, and `tests/test_git.py` reads the literal
   path `entrypoint/executor.py`. Both would silently stop covering or break after the move, so they are updated.
