### Strategy Rationale

The intent is accepted as written. It is small (ten modules, all under 230 lines), bounded (79 findings measured at
planning time with `scripts/self_explaining_comments.find_comments_and_docstrings`: 72 docstrings and 7 comments), and
it lowers system entropy by making the self-explaining rule true for one more slice of the `flow` package. Splitting it
further would cost more in pipeline overhead (review, CI, ledger rows per child) than the risk it removes. So it runs as
one plan on one execution branch.

Order: test first (red), then clean up the modules in two batches grouped by how hard they are, then run the
verification gate. Batch A holds the seven docstring-only modules (no comment decisions). Batch B holds `in_flight.py`
and `intent_questions.py`, which also carry inline and `#:` comments that each need a decision (delete, turn into
`# why:`, or extract a named helper), plus `ledger_reconcile.py`, which has the most docstrings for its size.

Aggregation: p_success is the product of the step success probabilities, with partial correlation credited because a
failure in a cleanup step is caught and fixed inside the same execution by the Step 4 gate:
`0.98 * 0.97 * 0.95 * 0.97 ≈ 0.876`, rounded up to `0.90` for that in-execution recovery. The bottleneck is Step 3 (the
comment decisions in `in_flight.py` and `intent_questions.py`, and possible lint-gate surprises on added `# why:`
lines). Entropy is the sum of step entropies `0.6 + 0.9 + 1.4 + 0.7 = 3.6`. Cost is the sum
`1.0 + 2.0 + 2.5 + 1.5 = 7.0`. Impact is judged qualitatively: a hygiene slice with no user-visible behaviour, but it
closes one part of a codebase-wide rule. Learning value is the maximum of the steps, and is low.

`EV = P(success) * Impact + mu * LearningValue - lambda * Delta_S_intent - Cost`, with `mu = 0.5`, `lambda = 0.3` and
`Delta_S_intent ≈ 1.2`: `EV = 0.90 * 40.0 + 0.5 * 1.5 - 0.3 * 1.2 - 7.0 = 36.00 + 0.75 - 0.36 - 7.0 = 29.39`. A more
conservative reading of `Delta_S` (`≈ 3.6`, the full plan entropy) gives `36.00 + 0.75 - 1.08 - 7.0 = 28.67`, which is
the value reported.
