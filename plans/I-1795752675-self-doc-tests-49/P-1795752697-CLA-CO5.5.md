   asserting an empty list and showing the file name and findings in the message.
5. Add two self-checks of the predicate so the guard cannot silently pass: one parametrised test feeding small source
   strings that must be flagged (a function docstring, a plain `# note` comment, a `#:` attribute comment) and one
   feeding sources that must pass (`# why: ...`, `# noqa: E501`, `# type: ignore[call-overload]`, `# pragma: no cover`,
   `# fmt: off`, a line-1 shebang, a `#` inside a string literal).
6. The new file itself carries no docstrings or comments (it is in the intent's scope and in lint's added-line scan).
7. Run `uv run pytest apps/sandbox-executor/tests/test_self_doc_tests_49.py` in the foreground: the existence and
