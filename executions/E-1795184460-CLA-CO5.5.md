  the token out of its `repr`. `build_request`, `default_opener`, `FETCH_ERRORS`, `API_ROOT` and `BASELINE_BRANCH` are
  imported from `scripts.ci_timing_gate`, not copied.
- Deviation: the run, commit and PR links are built from the configured server (`{server}/{repo}/actions/runs/{id}/job/
  {job_id}`, `/commit/{sha}` for a hex SHA, `/pull/{n}`) instead of copying the API's `html_url`, so only server-built
  `https://` links ever reach an `href`. The resulting link equals the API's job `html_url`.
- PR attribution matches the pull request's `base.repo.id` against the run's `repository.id` (the API's `base.repo`
  carries `id`, `url` and `name`, not `full_name`), falling back to `full_name` or the API URL.
