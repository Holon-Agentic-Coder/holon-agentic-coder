### Step 3: Introduce ExecuteState and ExecuteStage with named step methods

- `stages/execute.py` now holds `ExecuteState` (a slots dataclass with the shared fields, plus `target_branch`, which
  `resume_point` needs for `fetch_base`) and `ExecuteStage`. `ExecuteStage.steps()` returns `preflight`,
  `admit_and_refresh_plan`, `resume_point`, `salvage_partial`, `dispatch_executor`, `adopt_execution_branch`,
  `check_container_outcome` and `guard_empty_diff`, in that order. `run()` logs `Starting Stage 3: Plan Execution`,
  returns the first non-None step result and otherwise returns `record_execution()`. The helper methods are `_fail`
  (`_stage_failure` for Stage 3), `_bare_failure` (the unlogged, unstored result that the no-plan-branch and veto exits
  return, as before), `_dry_run_result` and `_decomposed_outcome`.
- `run_execute_stage(context, resume_partial=False)` is now `return ExecuteStage(context, resume_partial).run()`, with
  no `noqa`. The long decision-semantics docstring moved to the class. The file has no `noqa` comment left.
- Every patched collaborator (`_dispatch_role`, `fetch_base`, `publish_new_child_branches`, `changed_paths`,
  `_resolve_branch_ref` and the rest) is still imported into `execute.py` and looked up through module globals when a
  method runs. Statement order is kept: `push_error` is computed before the held-failure check and reported after the
  exit-code check, the ambiguity failure still has no `exit_code`, and `refresh_payload(context)` is still spread last.
- `execute.py` is 421 lines (budget 431), so the `execute_state.py` fallback was not needed. Ruff is clean (each method
  is within the C901, PLR0911, PLR0912, PLR0913 and PLR0915 limits).
- **Declared deviation (same reason as Step 2):** `flow/__init__.py` re-exports `ExecuteStage` and `ExecuteState`.
- Verification: `tests/flow` gave 1140 passed. The top-level set (`test_partial_salvage.py`, `test_resume_tip.py`,
  `test_complexity_gate.py`, `test_entrypoint_imports.py`, `test_unique_stage_ids.py`, `test_ref_names.py`) gave 105
  passed.
