### Implementation Details (No code blocks, only logic/steps)

1. Run `uv run task test` once in the foreground (it runs `pytest -n auto --dist worksteal` excluding integration and
   stress). Record the pass/fail count and the pytest-reported time. The intent names `uv run pytest`, and

2. Run `uv run task lint` (uv lock check, ruff check, ruff format check, module budgets) in the foreground.
3. Run `uv run task lint-docs` in the foreground.
4. Run the final greps:
   - `_update_directory_index` across the repository, excluding `plans/` and `executions/` history, finds nothing.
   - `git ls-files` lists no `index.json` under `holon-knowledge/kb` or `holon-knowledge/wisdom`.
   - `git diff --name-only main...HEAD` is a subset of the touch set plus the three deleted `holon-knowledge` files.
5. Write the execution report. Include the Step 2 parity probe output (counts and stale ids), test counts and time, lint
   results, and the operator note about one-time modify/delete conflicts on in-flight branches.
6. If anything fails, fix only within the touch set and re-run just the failing command once, then the full suite once.
   No open-ended re-runs, and never background a command.
