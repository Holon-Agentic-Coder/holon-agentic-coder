- `--collect-only` on list A shows the duplicated node under `<Package flow>`:

  ```text
  <Package flow>
    <Package stages>
      <Module test_children.py>
    <Module test_git_refs.py>
    <Package stages>
      <Module test_replan_request.py>
  ```

- Root cause confirmed: pytest 9.1 parses a conftest lazily onto the first `Directory`/`Package` collector for its
  path, and `Session.collect` skips its collection cache (`handle_dupes = False`) for a single file part, so a later
  file argument re-collects the directory into new nodes that never receive the conftest fixtures.
