### Step 3: Host-side attempt guard

- Added `flow/conflict_resolver_attempt.py`: `snapshot_merge`, `check_attempt`, `stage_resolution`, `reset_attempt`,
  `save_attempt_diff` (private definitions with public names bound by assignment, see Step 1).
- Hypothesis result: snapshotting the index stage entries, the untracked set, `HEAD` and `MERGE_HEAD`, plus
  `git diff --name-only -z`, detects every listed out-of-set edit and git write (`git add` of an out-of-set or an in-set
  path, a commit, `git merge --abort`). `git checkout -m` recreates markers for content and add/add conflicts, but
  **not** for modify/delete: git refuses with `path 'X' does not have all necessary versions`. The reset therefore
  restores a one-sided conflict from the surviving stage blob with `git checkout-index -f --stage=N`, which puts back
  exactly what the merge left in the tree. Both modify/delete directions are covered, so no conflict kind needs to fail
  closed early.
- Deviation: the snapshot keeps every index stage entry, conflict paths included (the plan excluded them). The agent
  never has a reason to touch the index, so a `git add` of a conflict path is also caught as tampering.
- Saved diffs go to `tmp/conflict-resolver/<label>.diff` and are excluded from the new-file check, so a saved artefact
  never fails the next tier.
- 15 tests in `tests/flow/test_conflict_resolver_attempt.py` on real merges.

### Step 4: Escalation loop and `conflict_code_resolver(context)`

- Added `flow/conflict_resolver_role.py`: `conflict_code_resolver` is a frozen callable class bound by assignment (see
  Step 1), so `conflict_code_resolver(context)` returns an object satisfying `CodeResolver`.
- Pre-dispatch block for `holon-config/hygiene/module_budgets.json` without `module_budget_change`.
- Per tier: write the role input,
  `_dispatch_role(context, CONFLICT_RESOLVER_ROLE, [transport, agent, tier, --result-file=transport], result_file=..., target_worktree=worktree)`,
  read the verdict (a non-zero exit, a dispatch exception or a file still holding the input is `agent_failed`), run
  `check_attempt`. Tampering, a failed reset or a failed staging stops at once; a `resolved` verdict with a clean check
  is staged; anything else saves the diff, resets and takes `next_tier`. The tier travels as the positional model
  argument, so `launcher/role_dispatch.py` needed no change.
- Deviation: the transport file lives in `~/.holon/tmp` (as the Stage 4 resolver's does), not under the worktree's
  `tmp/`, so it can never appear as an untracked file in the merge; it is always removed after the attempt.
- Hardening added in this step: `save_attempt_diff` writes a self-ignoring `.gitignore` (`*`) into
  `tmp/conflict-resolver/`, so the kept artefacts can never be swept into a commit even in a repository whose `tmp/` is
  not ignored.
- `CodeResolution.test_result` is redacted with `redact_agent_secrets` and capped at 500 characters before it reaches
  the `target_sync` row. `SyncRequest.code_resolver` keeps its fail-closed default.
- 9 tests in `tests/flow/test_conflict_resolver_role.py` through the real `sync_with_target`: first-tier success,
