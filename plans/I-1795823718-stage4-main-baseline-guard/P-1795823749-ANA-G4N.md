   `inspect_main_baseline(repo_dir, target_branch, head_ref, *, check_names=None, proxy_env=None, seams=None) -> BaselineFailure | None`:

   - Probe head checks on that SHA via `seams.probe_head_checks` or `gh_head_checks_probe(repo_dir, proxy_env)`; return
     `None` if `None` or no guarded checks are failed.
   - Collect failing paths for each failed guarded check and compute PR diff paths; compute
     `untouched = sorted(p for p in failing_paths if p not in pr_paths)`.
   - Return `BaselineFailure` only when `untouched` is non-empty; otherwise return `None`.

     `failing_checks`, `failing_paths`, `untouched_paths`, and `reason`.
