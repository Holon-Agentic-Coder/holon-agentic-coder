   `budgets = config.turn_budgets or TurnBudgets()`, `turn_observable = bool(config.watch_path or config.watch_tree)`,
   `seen_file = _file_state(config.watch_path)`, `seen_tree = _tree_mtime(config.watch_tree)`, and

2. Add `_spawn_turn_process(request: TurnRequest) -> Any` that calls `build_turn_env(request.config.env)`, builds
   `popen_kwargs` (`cwd`, `env`, `stdout=subprocess.PIPE`, `stderr=subprocess.PIPE`, `start_new_session=True`), and
   invokes `request.config.popen_factory` with an open binary handle to `stdin_file` when
   `stdin_file is not None and os.path.exists(stdin_file)` or without `stdin` otherwise. Note on environment overlay
   discipline: `build_turn_env` behavior (`DOCKER_CLI_HINTS=false`) is preserved unchanged for spawned agent runner
   child processes and already covered by `TestTurnExecutionEnvironment` in `apps/sandbox-executor/tests/test_turns.py`.
3. Add `_start_stream_readers(proc: Any) -> list[_StreamReader]` that constructs
   `[_StreamReader(proc.stdout), _StreamReader(proc.stderr)]` (using the module-level `_StreamReader` name so test
   patches continue to intercept it), starts both threads, and returns the list.
4. Add `_poll_tool_progress(state: _SupervisionState, config: TurnConfig, pid: int, now: float) -> None` that checks
   whether `tool_sampler` or `child_lister` is configured and whether
   `state.last_tool_scan is None or now - state.last_tool_scan >= TOOL_SCAN_INTERVAL_SECONDS`; updates
   `state.last_tool_scan`, `state.live_children`, and `state.seen_tools`, and resets
   `state.last_activity = state.last_progress = now` and `state.streaming = False` when
   `tool_cpu_used(state.seen_tools, sample) >= TOOL_CPU_PROGRESS_SECONDS`.
5. Add
   `_poll_progress(state: _SupervisionState, config: TurnConfig, readers: list[_StreamReader], pid: int, now: float) -> None`
   that updates stream activity (`seen_counts`, `last_activity`, `streaming = True`), checks `watch_path` via
   `_file_state`, checks `watch_tree` every `TREE_SCAN_INTERVAL_SECONDS` via `_tree_mtime`, and calls
   `_poll_tool_progress(state, config, pid, now)`.
6. Add `_evaluate_breach(state: _SupervisionState, config: TurnConfig, now: float) -> BudgetBreach | None` that computes
   `stall_window = _stall_window(state.budgets, state.streaming, bool(state.live_children))`, checks
   `_turn_breach(...)`, checks stall timeout
   (`state.budgets.stall_seconds > 0 and now - state.last_activity >= stall_window`), and checks
   `config.stage_timer.breached()`.
7. Add
   `_supervise_process(proc: Any, readers: list[_StreamReader], config: TurnConfig, state: _SupervisionState) -> BudgetBreach | None`
   that runs the `while proc.poll() is None:` loop inside `try ... except BaseException:`, polls progress, evaluates
   breaches, logs breach and live commands on stop, calls `_terminate_group(proc, config)`, sleeps
   `config.poll_interval` when continuing, and ensures `_terminate_group(proc, config)` runs on `BaseException` if
   `proc.poll() is None` before re-raising.
8. Add `_drain_readers(proc: Any, readers: list[_StreamReader], config: TurnConfig) -> tuple[str, str]` that joins
   readers with module-level `READER_JOIN_TIMEOUT_SECONDS`, sends `SIGTERM` then `SIGKILL` to process group `proc.pid`
   (guarded by `proc.pid != config.getpgid(0)` and `contextlib.suppress(OSError)`) if any reader remains alive, logs
   warnings identically to the original implementation, and returns `(readers[0].text(), readers[1].text())`.
9. Rewrite `run_turn(cmd: list[str] | TurnRequest, *, config: TurnConfig | None = None, **kwargs: Any) -> TurnResult`
   without any `# noqa` comment: resolve request via `_resolve_turn_request`, record `start = cfg.clock()`, spawn
   process (returning `TurnResult(returncode=127, stderr=f"Failed to start agent: {exc}", elapsed_seconds=0.0)` on
   `OSError`), start readers, initialize state, supervise process, record `background_commands` before draining when
   `breach is None`, drain readers, and return `TurnResult`.
10. Verify every new and modified function stays strictly within Ruff limits (`C901 <= 10`, `PLR0912 <= 12`,
    `PLR0913 <= 5`, `PLR0915 <= 50`), zero new `# noqa` suppressions are added, total line count of `turns.py` remains
    `<= 892`, and no docstrings or non-`# why:` comments are added.
