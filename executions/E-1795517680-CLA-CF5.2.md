## Planner Clarifications Kept

The six clarifications of the plan's `## Planner Autonomy Summary` are implemented as written:

1. **Real success against skipped success.** Every job ends with the step `Full run completed`. An earlier job counts as
   a real success only when the job and this step both concluded `success`. A skipped marker step sends the walk to the
   next older run; a missing marker step is `previous-run-unverified` and runs in full.
2. **Labels that change a result.** `RESULT_AFFECTING_LABELS` holds `timing-regression-accepted` and
   `module-budget-change`. A test scans the workflows for label names and fails on one that is not in the set.
3. **Re-runs run in full.** A run attempt above 1 is `rerun-attempt`.
4. **A push that changes no file** counts as bookkeeping-only and can skip.
5. **Module split.** Three script modules, each under 200 lines; the action calls `scripts.ci_bookkeeping_gate`.
6. **`docker-build.yml` grants `actions: read`** on its job.
