## Lessons

- pytest collects every `unittest.TestCase` subclass in a test module's namespace, so shared harness methods belong on
  plain mixins, never on imported `TestCase` classes.
- Ruff's isort merges `from m import a` with a `from m import b  # noqa: F401` line and hoists the `noqa` over the whole
  merged statement, which hides genuinely unused names. Put the `noqa` on each fixture name inside the parenthesised
  import list instead.
