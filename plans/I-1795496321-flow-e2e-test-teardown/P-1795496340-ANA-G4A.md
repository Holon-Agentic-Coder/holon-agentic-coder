   and `"HOLON_SKIP_PREFLIGHT"` so `test_environment_reference.py` remains satisfied.
2. Define domain exceptions and data structures:
   - `FailureCategory(enum.StrEnum)` with values `MODEL_OUTPUT = "model_output"` and `MACHINERY = "machinery"`.
   - `E2EError(RuntimeError)` base exception, `E2EModelOutputError(E2EError)` (retryable model-output assertion or
     generation failure), `E2EMachineryError(E2EError)` (non-retryable flow-machinery or infrastructure failure),
     `PrefixScopingError(E2EMachineryError)` (invalid intent prefix or out-of-prefix deletion attempt), and
     `ZeroPRGuardViolationError(E2EMachineryError)` (stray pull request detected for the test intent prefix or forbidden
     `--skip-review` usage).
   - `TeardownReport` frozen dataclass with fields `intent_prefix: str`, `removed_worktrees: tuple[str, ...]`,
     `deleted_local_branches: tuple[str, ...]`, `deleted_remote_branches: tuple[str, ...]`,
     `refused_refs: tuple[str, ...] = ()`, and `errors: tuple[str, ...] = ()`, plus a `summary_line()` method
     enumerating all deleted items.
   - `ZeroPRCheckResult` frozen dataclass with fields `intent_prefix: str`, `passed: bool`,
     `matching_prs: tuple[int, ...] = ()`, and `closed_prs: tuple[int, ...] = ()`.
   - `E2EAttemptOutcome` and `E2ERunOutcome` frozen dataclasses capturing `succeeded: bool`, `attempts_run: int`,
     `intent_prefix: str`, `stage_results: dict[str, Any]`, `teardown_reports: tuple[TeardownReport, ...]`,
     `zero_pr_results: tuple[ZeroPRCheckResult, ...]`, and `failure_category: FailureCategory | None`.
3. Implement strict intent-prefix validation and ref-scoping helpers:
   - `validate_e2e_intent_prefix(intent_prefix: str) -> str`: strips whitespace and requires `intent_prefix` to match
     `^I-\d+-[a-z0-9][a-z0-9-]*$` (a concrete root intent prefix with numeric timestamp and non-empty slug). Rejects
     empty strings, wildcards, path separators, `"main"`, `"master"`, `"HEAD"`, `"origin"`, or bare `"I-"` by raising
     `PrefixScopingError`.
   - `normalise_ref_name(ref_name: str) -> str`: strips leading `refs/heads/`, `refs/remotes/origin/`, or `origin/`
     without stripping internal slashes.
   - `is_ref_within_intent_prefix(ref_name: str, intent_prefix: str, worktree_branch: str | None = None) -> bool`:
     validates `intent_prefix`, normalises `ref_name`, refuses protected branches (`main`, `master`, `HEAD`), and
     returns `True` only when `normalised == validated_prefix` or `normalised.startswith(f"{validated_prefix}/")` (or
     when `worktree_branch` is provided, starts with `flow-`, embeds the intent's slug, and
     `normalised == worktree_branch`). A sibling prefix like `I-100-e2e-other/_` never matches `I-100-e2e`.
   - `assert_refs_within_intent_prefix(refs: Iterable[str], intent_prefix: str, worktree_branch: str | None = None) -> tuple[str, ...]`:
     validates that every ref in `refs` satisfies `is_ref_within_intent_prefix`; raises `PrefixScopingError` naming any
     out-of-scope ref before any deletion can occur.
4. Implement unconditional teardown (`teardown_e2e_intent`):
   - Accepts `repo_dir: str`, `intent_prefix: str`, optional `disposable_worktree: str | None = None`, optional
     `worktree_branch: str | None = None`, optional `candidate_refs: Iterable[str] | None = None`, and an injectable
     `git_runner` (defaulting to `sandbox_executor.git.run_git`).
   - Validates `intent_prefix` via `validate_e2e_intent_prefix`. If `candidate_refs` is passed, validates every
     candidate via `assert_refs_within_intent_prefix` and raises `PrefixScopingError` without touching git if any
     candidate lies outside `intent_prefix`.
   - Removes the disposable worktree (and any `f"{disposable_worktree}-rev*"` reviewer worktrees) after verifying the
     path is not `repo_dir` and is not on `main`/`master`, running `git worktree remove --force <path>` followed by
     `git worktree prune`, and records removed paths in `removed_worktrees`.
   - Enumerates local branches via `git for-each-ref --format=%(refname:short) refs/heads/`, filters strictly with
     `is_ref_within_intent_prefix`, deletes each matching branch with `git branch -D <branch>`, and records every
     deleted branch in `deleted_local_branches`.
   - Enumerates remote branches on `origin` (when an `origin` remote exists) via `git ls-remote --heads origin` and
     `git for-each-ref --format=%(refname) refs/remotes/origin/`, filters strictly with `is_ref_within_intent_prefix`,
     deletes each matching remote branch on `origin` via `git push origin --delete <branch>` and
     `git update-ref -d refs/remotes/origin/<branch>`, and records every deleted remote branch in
     `deleted_remote_branches`.

5. Implement the Zero-PR Guard and `--skip-review` prohibition (`assert_no_skip_review_flag` and
   `enforce_zero_pr_guard`):
   - `assert_no_skip_review_flag(cli_args: Sequence[str] = (), options: Mapping[str, Any] | None = None) -> None`:
     raises `ZeroPRGuardViolationError` if `"--skip-review"` or any `"--skip-review=..."` token appears in `cli_args` or
     if `"skip_review"` appears in `options`.
   - `enforce_zero_pr_guard(repo_dir: str, intent_prefix: str, worktree_branch: str | None = None, gh_runner: Callable[..., subprocess.CompletedProcess[str]] | None = None) -> ZeroPRCheckResult`:
     - Validates `intent_prefix`.
     - Queries pull requests via `gh_runner` (or `GitHubAdapter(repo_dir).gh` when `gh` is on `PATH` and `gh_runner` is
       not injected) with `["pr", "list", "--state", "all", "--json", "number,headRefName,baseRefName,state"]`.
     - Filters PR items where `headRefName` or `baseRefName` satisfies
       `is_ref_within_intent_prefix(..., intent_prefix, worktree_branch)`.
     - For every matching PR whose `state` is `"OPEN"` (case-insensitive), closes it via
       `["pr", "close", str(number), "--comment", f"Closed stray E2E pull request for disposable intent {intent_prefix}."]`
       and records its number in `closed_prs`.
     - If `matching_prs` is non-empty, raises `ZeroPRGuardViolationError` naming the stray PR numbers, branches, and
       closed PR numbers.
     - Otherwise returns `ZeroPRCheckResult(intent_prefix=intent_prefix, passed=True)`.
6. Implement pre-PR flow execution and retry classification (`E2EPipelineEngine`, `classify_attempt_failure`, and
   `run_e2e_with_retry`):
   - `E2EPipelineEngine(PipelineEngine)`: subclasses `PipelineEngine` to stop cleanly at the Stage 4
     (`FlowStage.REVIEW`) pre-PR boundary after Stages 1 (`INTENT`), 2 (`PLAN`), and 3 (`EXECUTE`) succeed. When
     `execute_stage(FlowStage.REVIEW)` is reached, it returns
     `StageResult(stage=FlowStage.REVIEW, status=StageStatus.HALTED_FOR_HUMAN, payload={"halted_for_human": True, "stopped_before_pr": True})`
     without invoking `GitHubAdapter.open_or_update` or `create_or_update_pr`, and sets `context.skip_calibrate = True`
     so Stage 5 does not run.
   - `classify_attempt_failure(error: BaseException | None = None, stage_results: Mapping[str, StageResult] | None = None) -> FailureCategory`:
     - Returns `FailureCategory.MACHINERY` for `E2EMachineryError`, `LocalLLMConfigError`, `LedgerRewriteError`,
       `TypeError`, `AttributeError`, `KeyError`, `ValueError` (unless `E2EModelOutputError`), and for stage errors
       matching infrastructure/machinery patterns (`unhandled exception`, `could not fetch`, `host push of`,
       `host fetch of`, `could not check out`, `without an active`, `unique-id`, `not valid JSON`, `docker`,
       `worktree`).
     - Returns `FailureCategory.MODEL_OUTPUT` for `E2EModelOutputError` and for stage errors/payloads caused by model
       generation (`metrics validation failed`, `empty or invalid plan file`, `no planner agent produced`,
       `over_budget`, `exceeds the entropy budget`, `touch_set_violation`, `outside the plan's touch set`, `empty_diff`,
       `changed 0 path(s)`, role agent non-zero exit after turn, or model-output assertion failure).
     - Defaults fail-closed to `FailureCategory.MACHINERY` for any unrecognised failure.
   - `run_e2e_with_retry`: accepts an attempt callable (or `FlowContext` builder), `repo_dir`, `base_slug`,
     `max_attempts: int = 3` (validated within `1 <= max_attempts <= 5`), `gh_runner`, and `git_runner`. On each

     executes even when `enforce_zero_pr_guard` raises `ZeroPRGuardViolationError`), retries only
     `FailureCategory.MODEL_OUTPUT` up to `max_attempts`, and fails immediately on `FailureCategory.MACHINERY`.
