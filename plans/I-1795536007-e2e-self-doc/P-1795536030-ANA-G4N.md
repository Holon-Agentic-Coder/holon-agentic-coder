   - Standard tool pragmas matching `# noqa` (with optional `: CODE, ...`), `# type: ignore` (with optional `[code]`),
     or `# pragma: no cover`.
4. Add parametrized pytest cases over all four scoped modules asserting:
   - `_find_docstrings(source) == []`
   - `_find_disallowed_comments(source) == []`
5. Add focused unit tests on `_find_docstrings` and `_find_disallowed_comments` using synthetic source strings to prove
   they flag module/class/function docstrings and explanatory comments while permitting `# noqa: E501`,
   `# type: ignore[arg-type]`, `# pragma: no cover`, line-1 shebangs, and line-1/2 encoding declarations.
6. Ensure `test_e2e_self_doc.py` itself is clean, strictly typed, and passes Ruff lint and formatting rules.
