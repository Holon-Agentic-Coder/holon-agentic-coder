### Intent & Git Integration

- **Step Intent:** Decide `scoped` or `full` for each pass, failing closed, and build the scoped `ReviewRequest`.
- **Git branch:** the execution branch of this plan
- **Sub‑intent:** NONE

### Implementation Details (No code blocks, only logic/steps)

1. `delta_review_mode.py`: a frozen `ReviewMode(mode, reason)` value and the decision table, kept as a pure function
   over plain inputs. The pass is `full` when any of these hold:
   - the limit is 0;
   - there is no last reviewed head;
   - the last reviewed head is not an ancestor of the head;
   - the range contains a non-mechanical target merge;
   - the delta is empty or over the limit;
   - the chain has reached 3 scoped passes;
   - any reviewer on the last gate returned CRITICAL. Otherwise the pass is `scoped`.
2. `delta_review_git.py`: the git probes. These are the ancestry check, merge commits in the range, numstat line counts
   over `reviewable_pathspecs()`, the delta diff, and `git show head:path` for the context files. Each probe raises a
   typed error on failure.
3. `delta_review.py` (≤ 200 lines) is the public surface:
   - `delta_state_of`, `begin_review_pass`, `end_review_pass`, `record_addressed_findings` and `current_decision` manage
     `context.review_state["delta"]`, with a fail-closed parser.
   - `decide_review_mode(context, repo_dir, head)` wraps `_decide_from_git`. Any exception gives
     `full ("delta check failed")`.
   - `end_review_pass` sets the last reviewed head only when every reviewer completed. A full pass anchors the chain,
     and a scoped pass extends it.
4. `delta_review_request.py`: `build_delta_request(...)` builds the request:
   - `base_ref` is the last reviewed head and the diff is the delta;
   - the context files go through `redact_agent_secrets`, each capped at the context-bytes limit with a truncation
     marker, and the total capped at four times that limit;
   - the addressed findings are capped at 50 rows.
5. `delta_review_forwarding.py`: `forward_scoped_decision`, `load_forwarded_decision` and `discard_forwarded_decision`
   write, read and remove the JSON decision file under `.holon/review/`. A malformed file loads as `None`, which means a
   full review.
6. `review_request.py`: add keyword-only, default-`None` `context_files` and `addressed_findings` rendering to
   `build_review_request`. A full request stays byte-identical to today's.
