### Strategy Rationale

The intent is small, behaviour-preserving and exactly matches a pattern the repository has already executed many times,
so it is accepted as-is with a conservative, single-branch plan. The one non-obvious finding from planning is that the
shared `self_doc_scanner` rejects `# why:` and `# fmt:` comments, which would make the intent's own allowed comments
fail; the plan solves this inside the new scoped test instead of editing the shared scanner (which sits outside the
scope and backs a 146-module registry test).

Aggregation: entropy is the sum of step entropies (`0.2 + 0.8 + 0.9 + 1.0 + 0.5 = 3.4`). Cost is the sum
(`0.5 + 1.5 + 1.5 + 2.0 + 1.5 = 7.0`). Overall p_success is a qualitative judgement, not a product: the steps are
strongly correlated (same author, same mechanics), so the bottleneck Steps 4 and 5 at 0.93 set it at 0.92. Impact is 38,
the sum of step impacts, reflecting a narrow hygiene win that makes the self-explaining rule true for one more package.
Learning value is low (1.5). Overall
`EV = 0.92 * 38.0 + 0.5 * 1.5 - 0.3 * 3.4 - 7.0 = 34.96 + 0.75 - 1.02 - 7.0 = 27.69`, reported as 27.7.
