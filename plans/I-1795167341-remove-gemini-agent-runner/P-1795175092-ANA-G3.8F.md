## Plan Description & Strategy

This plan eliminates the dead `gemini-agent` runner and its Docker container build target while safeguarding Gemini
model support through `antigravity-agent`.

The `gemini-agent` runner was superseded by `antigravity-agent` and cannot run flows because it lacks a runner ticker in
`AGENT_TICKERS`. Retaining it introduces maintenance friction and slows down container image builds. The plan removes
`agent-gemini` from Docker build configurations and documentation, prunes `GeminiAgentRunner` and associated runner maps
from the Python codebase, implements clear redirection error messages for users attempting to pass `--agent gemini` or
`--agent gemini-agent`, updates existing test suites across all affected modules, and validates all changes through
automated tests and linters.
