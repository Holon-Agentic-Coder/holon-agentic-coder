## Plan Description & Strategy

This plan implements automatic git staging and committing of promoted knowledge base and wisdom heuristics produced
during Stage 5 calibration in `apps/sandbox-executor/src/sandbox_executor/flow.py`. Following
`promote_pending_candidates()`, newly generated artifacts in `holon-knowledge/kb` and `holon-knowledge/wisdom` are
staged and committed to the `/calibrated` branch alongside the reconciliation commit using `calibration_commit_env()`.
The existing branch synchronisation logic then pushes `/calibrated` to origin and fast-forwards it into
`context.execution_branch`, ensuring promoted continuous learning artifacts appear in the pull request diff and
canonical `main` history. Clean no-op handling ensures runs where no candidates qualify or no files change proceed
seamlessly. Comprehensive hermetic unit tests are added to `apps/sandbox-executor/tests/test_flow.py`.

### Intent & Git Integration

- **Step Intent:** Add `_commit_stage5_promoted_artifacts` helper and call it from `run_calibrate_stage` after
  `promote_pending_candidates` successfully writes KB and wisdom artifacts on the `/calibrated` branch.
- **Git branch:**
  `I-1793942491-stage-5-commits-promoted-knowledge-and-wisdom/P-1793942508-antigravity-agent-gemini-3.8-flash-medium/E-commit-promoted-artifacts/_`
- **Sub‑intent:** NONE

### Implementation Details (No code blocks, only logic/steps)

- Define `_commit_stage5_promoted_artifacts(context: FlowContext, repo_dir: str, promoted_count: int = 0) -> None` in
  `apps/sandbox-executor/src/sandbox_executor/flow.py` following `_commit_stage5_reconciliation`.
- Guard conditions for early no-op:
  - If `promoted_count == 0` or `not context.calibrated_branch`, return immediately.
  - Verify current HEAD ref via `run_git(["rev-parse", "--abbrev-ref", "HEAD"], cwd=repo_dir, check=False)`. If HEAD is
    not `context.calibrated_branch`, log an informative message and return without committing.
  - Locate existing promotion target directories (`holon-knowledge/kb` and `holon-knowledge/wisdom`). If neither exists
    in `repo_dir`, return cleanly.
  - Stage the target paths via `run_git(["add", *existing_paths], cwd=repo_dir, check=False)`.
  - Check status with `run_git(["status", "--porcelain", "--", *existing_paths], cwd=repo_dir, check=False)`. If output
    is empty, return cleanly without creating an empty commit.
  - Execute git commit with message `chore(calibration): record stage 5 promoted knowledge and wisdom` using environment
    `env=calibration_commit_env()` scoped to `--` and the existing promotion directories.
  - Catch git failure gracefully: if `nothing to commit` is reported in stdout/stderr, treat as safe no-op; otherwise
    redact stderr using `CredentialRedactor.redact_text` and log a warning without raising, ensuring Stage 5 completes
    reliably.
- In `run_calibrate_stage`:
  - After `promoted_candidates = promote_pending_candidates(...)`:
  - If `promoted_candidates` and `calibration_succeeded` and `not context.dry_run`: invoke
    `_commit_stage5_promoted_artifacts(context, repo_dir, len(promoted_candidates))`.
  - If `not calibration_succeeded`, log that promoted candidate artifacts remain uncommitted due to calibration failure.
  - Retain the existing subsequent logic that pushes `context.calibrated_branch` and fast-forwards
    `context.execution_branch` (`merge --ff-only`), guaranteeing that the promoted artifacts commit is propagated to the
    PR diff and main history.
