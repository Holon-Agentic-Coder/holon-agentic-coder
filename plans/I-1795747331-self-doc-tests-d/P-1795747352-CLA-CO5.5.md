  test to state the behaviour in domain language (for example `test_ledger_lock_timeout` becomes
  `test_ledger_lock_raises_after_timeout_when_held`). Keep the `test_` prefix, keep names unique in the module, and keep
  parametrize IDs unchanged.

  does.
- **Section banner comments** (`# --- ... ---`) and **attribute doc comments** (`#:`): delete them. If a banner groups a
  run of tests whose shared setup is not named, the test names carry the grouping instead. Do not reorder tests.
- **Inline explanatory comments:** delete them if they restate the code. If they explain a non-obvious step, extract a
  well-named local helper or a named constant (inside the same file). If they record a reason (an incident, a platform
  quirk, a timing constraint), rewrite them as `# why: <reason>`.
- **Never touch** string literals, assertion expressions, log or error message text, fixtures' behaviour, or any
  `conftest.py`.
