## Plan Description & Strategy

Harden `AgentRunner.resolve_credentials` in `apps/sandbox-executor/src/sandbox_executor/agent_runner.py`:

1. Missing parent directories of each unpacked config file are created one by one with mode 0o700 (and chmod-ed to 0o700

`cleanup_ephemeral_credentials` are unchanged. Note that only files (not the created directories) are registered as
ephemeral, exactly as today. Three tests are added to `tests/test_agent_runner.py`; existing tests are not modified.

### Implementation Details (No code blocks, only logic/steps)

1. Add module constants near the top of `agent_runner.py`, named in the style of `launcher/env_files.py`:
   `_OWNER_ONLY_DIR_MODE = 0o700` and `_OWNER_ONLY_FILE_MODE = 0o600`.
2. Add `from sandbox_executor.redaction import redact_agent_secrets` to the import block (ruff isort order). Confirmed:
   `redaction.py` imports only stdlib, so no cycle.
3. Add a module-level helper `_make_private_dirs(directory: str) -> None` with a docstring: walk upward from `directory`
   collecting each component that does not exist (use `os.path.isdir` / `os.path.lexists` on the real filesystem,
   stopping at the first existing ancestor), then create them top-down with `os.mkdir(path, _OWNER_ONLY_DIR_MODE)`
   followed by `os.chmod(path, _OWNER_ONLY_DIR_MODE)`. Treat `FileExistsError` from `os.mkdir` as "already present, do
   not chmod" so a concurrent creator or a pre-existing directory keeps its mode. Pre-existing directories (including
   the home directory) are never chmod-ed.
4. Add a module-level helper `_write_private_file(path: str, content: str) -> None` with a docstring: open with
   `os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC | os.O_NOFOLLOW, _OWNER_ONLY_FILE_MODE)`, immediately
   `os.fchmod(fd, _OWNER_ONLY_FILE_MODE)` (covers the pre-existing file case), then wrap with `os.fdopen(fd, "w")` and
   write the content. If `fdopen` itself fails, close the descriptor before re-raising (a `try`/`except` around `fdopen`
   only), mirroring `write_env_file`.
5. In `resolve_credentials`, replace `os.makedirs(os.path.dirname(full_dest), exist_ok=True)` with
   `_make_private_dirs(os.path.dirname(full_dest))` and replace the `with open(full_dest, "w")` block with
   `_write_private_file(full_dest, content)`. Keep the realpath-based traversal check, the `ValueError` message
   `Path traversal detected in config_files path: ...`, the `_ephemeral_files.append(full_dest)` and the `atexit`
   registration exactly as they are, in the same order.
6. Replace the warning with lazy formatting:
   `logger.warning("Failed to process secret bundle %s: %s", secret_bundle_path, redact_agent_secrets(str(e)))`. The
   traversal test checks `str(mock_warn.call_args)` for `"Path traversal detected"`, which survives both the format
   change and redaction.
7. Optionally remove the redundant function-local `import json` (the module already imports `json` at line 2) to offset
   added lines; do not touch other methods.
8. Check the line count stays well under 782 (expected about 715) and that `resolve_credentials` complexity does not
   increase (the helpers remove a `with` block from it).
