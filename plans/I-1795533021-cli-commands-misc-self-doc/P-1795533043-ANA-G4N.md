2. Define a tuple `SCOPED_MODULES` listing all twelve filenames (`__init__.py`, `calibrate.py`, `consult.py`,

   `ast.walk`, recording `(lineno, node_name)` for any non-None docstring.
4. Implement a tokenizer comment checker using `tokenize.generate_tokens(io.StringIO(source).readline)` that inspects
   every `tokenize.COMMENT` token and allows only:
   - Shebang lines (`#!`) on line 1.
   - PEP 263 encoding declarations (`coding[:=]\s*[-\w.]+`) on lines 1 or 2.
   - Tool pragmas matching `#\s*(noqa\b|type:\s*ignore\b|pragma:\s*no\s+cover\b)` (case-insensitive on pragma keywords
     as appropriate). Any other comment is collected with `(lineno, comment_text)` as a violation.
5. Add parametrized tests over `SCOPED_MODULES` asserting:
   - Every scoped module file exists.
   - Zero docstrings are present in the module AST.
   - Zero non-allowlisted comments are present in the module token stream.
6. Add a small unit test verifying the comment-allowlist helper itself (accepts `# noqa: E501`,
   `# type: ignore[arg-type]`, `# pragma: no cover`, shebang on line 1, encoding on line 1–2; rejects ordinary
   explanatory comments) so the guard cannot silently become a no-op.
