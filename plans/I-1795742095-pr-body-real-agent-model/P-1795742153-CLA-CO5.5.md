  placeholder (for example a payload restored from a checkpoint, or an intent carrying `"agent": "N/A"`) still hides a
  real runner. The goal asks for exactly this rule, and it is still missing.
- A body is rendered with `N/A` whenever the context hands over an empty runner. `FlowContext` defaults to real values,
  and `from_dict` falls back to legacy defaults, so this can only happen when someone builds the context directly with
  blanks.
- Since I-1795685390 there is one runner per checkpoint, so `context.agent` / `context.model` is the runner that planned
  the flow. The plan stage dispatches the planner with exactly these values (`flow/stages/plan.py:120`).
