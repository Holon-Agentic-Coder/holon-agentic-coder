## Steps Executed

### Step 1: added-lines reader `scripts/self_explaining_diff.py`

- `ChangedFile(path, added_lines, text)` frozen dataclass; `merge_base(root)` (`None` without `origin/main`);
  `added_line_numbers(diff_text)` parses `git diff -U0` (`+c`, `+c,d`, `+c,0`), honouring `+++ b/` only inside a file
  header so an added line beginning with `++` is never read as a header.
- Branch mode diffs the working tree against the merge base (`--diff-filter=ACMR`, renames detected so a pure rename adds
  nothing, submodules ignored) and adds untracked files as wholly added; staged mode uses `--cached` and reads the text
  from the index (`git show :path`). Non-UTF-8 files are skipped. `run_git` is reused from `module_budget_freeze`; diff
  and `show` output is read as bytes so a non-UTF-8 file cannot crash the decode.

### Step 2: comment and docstring finders `scripts/self_explaining_comments.py`

- `find_comments_and_docstrings(path, text)` returns `Finding(first_line, last_line, kind, text)` items. Python:
  docstrings via `ast` (module, class, function and async function, spanning `lineno..end_lineno`) and comments via
  `tokenize` `COMMENT` tokens. Hash languages (shell, extensionless `sh`/`bash` shebang files, Makefile, `*.mk`,
  Dockerfile, YAML, TOML): a per-line regex tokenizer that consumes double-quoted, single-quoted and backslash-escaped
  text and counts `#` only at line start or after whitespace. JavaScript (`.js`, `.mjs`, `.cjs`): one regex tokenizer
  over strings, template literals, `//`, `/* */` and `/** */` (JSDoc).
- Allowlist `is_allowed_comment`: line-1 shebang, line-1/2 `coding[:=]`, then the marker-stripped body starting with
  `REASON_PREFIX = "why:"` or one of `MACHINE_DIRECTIVE_PREFIXES` (`noqa`, `type:`, `pragma`, `fmt:`, `shellcheck`).
- The JavaScript "state machine" is expressed as an alternation regex (each alternative is one state); behaviour is
  the same and every function stays well inside the ruff complexity limits.

### Step 3: CLI `scripts/check_self_explaining.py`

- `main(argv) -> int` with `--staged` and `--root` (default resolved from `__file__`). A finding is a violation when its
  span intersects the file's added lines; each prints `path:line: added <kind> (...)` to stderr, then a count, exit 1.
  Without a merge base (branch mode) it prints `no merge base with origin/main; self-explaining check skipped` and
  exits 0.
- Self-application: `uv run python scripts/check_self_explaining.py` on the branch exits 0.
