     - Classify with `classify_job`:
       - `REAL_SUCCESS`: return `(ChainResult(run.head_sha, RULE_PREVIOUS_RUN_SUCCEEDED, where), walked_cancelled)`.
       - `GATE_SKIPPED`: continue walking.
       - `NOT_SUCCESSFUL` with `_is_cancelled_job(job)`: set `walked_cancelled = True`, record `first_cancelled` if not
         yet set, and continue walking.
       - Any other `NOT_SUCCESSFUL` (`failure`, `timed_out`, `in_progress`, etc.) or `UNVERIFIED`: stop immediately and
         return the failure `ChainResult`.
   - If the loop finishes without a `REAL_SUCCESS`: if `first_cancelled` is set and `len(runs) <= MAX_CHAIN_HOPS`,
