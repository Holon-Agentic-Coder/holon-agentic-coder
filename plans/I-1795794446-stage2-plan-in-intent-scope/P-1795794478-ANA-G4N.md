3. Implement `is_provenance_path(path: str) -> bool` that normalises the path via `normalise_touch_path` and returns

5. Implement extraction of recorded scope expansions from three sources:
   - `intent_data`: keys `"scope_expansion"` and `"scope_expansions"`.
   - `plan_row`: keys `"scope_expansion"` and `"scope_expansions"`.
   - `plan_content`: an explicit level-2 markdown section matching `^##\s+scope\s+expansions?\s*$` (case-insensitive,
     ignoring fenced code blocks), extracting bullet/numbered items and backticked or leading path tokens while ignoring
     placeholder words (`none`, `n/a`, `na`, `nil`, `no`, `not`).
6. Implement `_plan_touch_set_paths(plan_content: str, plan_row: Mapping[str, Any]) -> list[str]` that parses
   `## Touch Set` via `parse_touch_set_section(plan_content)` and also reads
   `TouchSet.from_row(plan_row.get("touch_set"))`, returning deduplicated normalised paths preserving order (excluding
   provenance paths).
7. Implement
   `out_of_scope_touch_set_paths(intent_data: Mapping[str, Any] | None, plan_content: str, plan_row: Mapping[str, Any] | None = None) -> list[str]`:
   - Read `raw_scope = (intent_data or {}).get("scope")`. If `raw_scope` is not a list or yields no normalised entries,
     return `[]` (unscoped intent).
   - Build `allowed = (*scope_entries, *expansion_entries)`.
   - Return every non-provenance touch-set path `path` for which
     `not any(entry_matches(entry, path) for entry in allowed)`.
8. Implement `plan_scope_failure_message(plan_branch: str, out_of_scope: list[str]) -> str` formatting a clear,
   actionable Stage 2 error message naming the plan branch, the offending paths, and instructing to either remove them
   from `## Touch Set` or record an explicit scope expansion on the plan or intent.
