these baseline findings (docstrings / non-allowlisted comments): `ledger_worktree.py` 9/9, `merge_git.py` 3/0,

sub-intent list. Step order: write the test first so it fails, clean the modules in three batches from smallest to
riskiest (`pipeline.py` last, because it is at its budget override of 431 lines and has the most comments that carry a
reason), then verify.

The main design choice is **delete, don't rename by default**. The existing public and private names are already
descriptive, and the suite patches private names in these modules (for example `process_reaper` is imported by
`flow/run_lock.py`, and tests patch module attributes). Renaming would risk breaking callers for little gain. A rename
or extraction is allowed only for a private symbol with zero references outside its module, including `tests/`. That
keeps each module's AST identical apart from removed docstrings, which Step 6 checks mechanically.

Aggregation: overall entropy is the sum of the step entropies (`0.2 + 1.0 + 0.8 + 1.5 + 1.5 + 0.5 = 5.5`). Cost is the
