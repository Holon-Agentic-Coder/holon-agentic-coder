- **Git branch:** same execution branch as Step 1
- **Sub‑intent:** NONE

### Implementation Details (No code blocks, only logic/steps)

1. In `apps/sandbox-executor/src/sandbox_executor/entrypoint/executor.py`, add a module-level constant for the excerpt
   size (for example `EMPTY_DIFF_EXCERPT_CHARS = 500`) and a typed, docstringed helper (for example
   `format_empty_diff_excerpt(agent_output_text: str, agent_output_bytes: int) -> str | None`) placed near
   `prepare_agent_output_block`. It returns `None` when the text is empty or whitespace-only; otherwise it takes the
   last `EMPTY_DIFF_EXCERPT_CHARS` characters of the (already redacted) text, passes them through `redact_agent_secrets`
   again as defence in depth, and returns a message such as "Agent output tail (last N of {agent_output_bytes} bytes,
   redacted):" followed by the excerpt on the next line.
2. In `main()`, inside the existing `if failure_reason:` block after `print(f"Error: {summary}", file=sys.stderr)`, emit
   the excerpt only when `failure_reason == EMPTY_DIFF_FAILURE_REASON`. To avoid adding a branch to `main()` (already
   carrying `# noqa: C901, PLR0912, PLR0915`), let a second small helper (for example
   `report_empty_diff_output(failure_reason, agent_output_text, agent_output_bytes)`) own the reason check and the
   print, so `main()` gains a single call statement. Pass `EMPTY_DIFF_FAILURE_REASON` from the existing local import or
   import it at the helper level from `sandbox_executor.git`.
3. Do not add any field to `exec_entry`; the summary row keeps `agent_output_bytes` only.
4. In `apps/sandbox-executor/tests/test_executor.py`:
   - Unit-test the helper: long output returns at most 500 excerpt characters (the tail end is present, the head is not)
     and mentions the byte count; a value matching a provider-token pattern in the tail (for example a `ghp_` style
     token, as used in existing redaction tests) is masked; empty and whitespace-only text return `None`.
   - Extend `_run_main_with_agent_diff` (or add a sibling) so the agent-run `run_cmd` result can carry custom stdout,
     capture `sys.stderr`, and assert: on empty_diff with non-empty output stderr contains the `Error:` line and the
     excerpt; with empty output stderr contains the `Error:` line and no excerpt header; on `diff_unverified` and on
     success no excerpt is printed; the summary row has the same keys as before (no agent text, `agent_output_bytes`
     present).
