### Implementation Details (No code blocks, only logic/steps)

1. Create `apps/sandbox-executor/src/sandbox_executor/intent_refresh.py` directly in the `sandbox_executor` package (not
   under `flow/`), with `from __future__ import annotations`, `logging`, `json`, `os`, `re` imports and a module
   `logger`.
2. Constants: `REFRESHED_INTENT_FIELDS = ("goal", "description", "rationale", "scope", "acceptance_criteria")`;
   `SELF_EXPLAINING_SENTENCE` holding the full sentence quoted in the intent (used in the error message);
   `SELF_EXPLAINING_MARKER = "code is self-explaining"`.
3. `class IntentContractError(ValueError)` for the refusal.
4. `goal_states_self_explaining_code(goal: object) -> bool`: false for non-strings; otherwise collapse whitespace with
   `re.sub(r"\s+", " ", goal)`, lowercase, test for the marker.
5. `read_intent_file(path: str) -> dict[str, Any]`: open UTF-8, `json.load`; raise `IntentContractError` naming the path
   when the payload is not a JSON object (a missing file already fails earlier in `flow.py` only on fresh runs, so also
   raise a clear `IntentContractError` when `os.path.isfile` is false).
6. `refresh_intent_text(context: Any, intent_path: str) -> list[str]`: read the file; for each field in
   `REFRESHED_INTENT_FIELDS` present in the file whose value differs from `context.intent_data.get(field)`, assign the
   new value into `context.intent_data` (mutating the dict in place, never replacing it, so every other key survives),
   then emit one line `Resume refreshed intent {field} from {intent_path}: the checkpoint held an older text.` via
   `logger.info` and `context.log`. Fields absent from the file keep their stored value. After the loop, if
   `goal_states_self_explaining_code(context.intent_data.get("goal"))` is false, raise `IntentContractError` with a
   message that names the intent file, states the resume is refused, and quotes `SELF_EXPLAINING_SENTENCE` as what the
   goal must contain. Return the list of changed field names.
7. Add `# why:` comments only where a reason is invisible in code (for example why fields absent from the file are kept
   and why the dict is mutated in place). No docstrings, no other comments. Keep every function well under ruff
   complexity limits; target under 80 lines total (limit 200).

### Strategy Rationale

The intent is precise, small and high-value: the goal is the contract every later stage judges against, and a stale goal
already let docstrings through review. Accepting it as written is the highest-EV path. Rejecting or deferring would
leave a known integrity hole, and splitting it would add overhead to a change of under 150 lines.

Aggregation: overall `p_success` (0.86) is bounded by the bottleneck chain (Steps 1, 2 and 5 at 0.93, 0.92 and 0.88).
The steps are correlated (the same small code), so the result sits slightly below the weakest step rather than at the
product `0.93 * 0.92 * 0.88 = 0.75`. Entropy and cost are sums (`0.9 + 0.8 + 0.5 + 1.2 + 0.8 = 4.2`;
`2.5 + 1.5 + 1.0 + 3.0 + 2.0 = 10.0`). Impact (70) is a qualitative judgement of the whole outcome, not the sum of step
impacts: it closes a silent contract bypass on every resume. Learning value is the sum of step values rounded down to
3.0, because the work is mostly exploitation.

Design choices:

- An allowlist of five refreshed keys means identity fields cannot change by construction, so there is no denylist to
  maintain.
- The refresh is hooked into `apply_run_switches` so both resume paths in `flow.py` get it with zero edits there. The
  hook is idempotent because that helper runs twice per resume.
- The refusal uses a whitespace- and case-tolerant marker, which avoids false refusals from line wrapping while still
  stopping a goal that drops the rule.

Assumption against the world ruleset: `holon-config/world/ruleset.md` section 2 asks for docstrings on public functions,
but the intent explicitly forbids them and the repository has already moved governed modules to the self-explaining
style (`tests/test_self_doc_modules.py`). The intent's explicit, newer instruction wins for the files it adds.
