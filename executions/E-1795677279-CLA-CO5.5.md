### Step 1: Baseline harness and pytest internals (done)

- Installed `pytest==9.1.1`. `_pytest/tmpdir.py` imports `make_numbered_dir` from `_pytest.pathlib` into its own
  namespace; `TempPathFactory.mktemp(basename, numbered=True)` calls it as
  `make_numbered_dir(root=self.getbasetemp(), prefix=basename, mode=0o700)`, and `tmp_path` goes through `_mk_tmp`,
  which calls `factory.mktemp(name, numbered=True)`. `make_numbered_dir` runs `find_suffixes` (an `os.scandir` of the
  whole root, case-insensitive prefix match) on every call and refreshes a `<prefix>current` symlink. `getbasetemp` uses
  the separate name `make_numbered_dir_with_cleanup` (whose internal `make_numbered_dir` reference lives in
  `_pytest.pathlib`), so replacing only `_pytest.tmpdir.make_numbered_dir` leaves the base temp's creation and retention
  to pytest.
- Dependency grep over `apps/sandbox-executor/tests`: no test reads the names `claude-home`, `env-files`,
  `layered-config` or `feature-worktree` from the base temp, and none uses a `<prefix>current` symlink or lists
  `getbasetemp()`. `repo_templates.shared_template` writes `shared-*` into the base temp's parent under xdist (the base
  temp itself otherwise), with fixed, non-numbered names, so it never collides with numbered names. The `current`
  symlink is therefore not kept.
- Deviation: `git worktree add` fails here because the repository's git directory is on a read-only mount
  (`Read-only file system`). The baseline is instead a throwaway `git clone --no-checkout` of the workspace at
  `/tmp/holon-bench/baseline`, detached at the merge base `412bed21`; it is never committed to. Both sides run with the
  shared virtual environment's interpreter directly (`/home/holon/.cache/holon-venv/bin/python -m pytest`) so the
  baseline never re-syncs the shared environment; the pyproject `pythonpath` puts each checkout's own `src` and `tests`
  first.
- Generator (`make_empty_tests.py`) and JUnit summariser (`summarise_junit.py`, count, p10, p25, median and sum of
  `testcase` times) live untracked in `/tmp/holon-bench/tools`.

### Step 2: Constant-time helpers in `tests/fast_tmp_dirs.py` (done)

- `NumberedDirAllocator`: per-`(root, prefix)` counter seeded by one scan with pytest's own suffix rule
  (`find_suffixes`, `parse_num`); `os.mkdir(path, mode)` is the claim; `FileExistsError` rescans and moves to
  `max(n + 1, rescan)`, at most `MAX_ATTEMPTS = 10` times, then raises `OSError`. Guarded by a `threading.Lock`. The key
  is the root as given (pytest's base temp is already resolved), which saves a `resolve()` per call.
- `install_fast_numbered_dirs()` replaces only `_pytest.tmpdir.make_numbered_dir` and returns the restore function.
- `PrivateTestDirs` / `new_private_test_dir(base_temp)`: `<base temp>/isolated/t<n>` (`0o700`) through its own
  allocator, so a stale `t<n>` from an earlier run is skipped, never reused.
- `ruff check` and `ruff format --check` pass; smoke test: 5,000 allocations in a fresh root gave 5,000 distinct paths
  (`1.88 s`, dominated by `mkdir` on the container's overlay file system).
