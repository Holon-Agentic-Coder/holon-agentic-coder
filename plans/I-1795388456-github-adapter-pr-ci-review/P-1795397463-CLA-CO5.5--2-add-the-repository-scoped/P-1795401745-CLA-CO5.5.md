### Implementation Details (No code blocks, only logic/steps)

1. Create `flow/github/adapter.py` with a module docstring stating it is the only `flow/github` module that spawns `gh`
   for the in-scope operations and that it spawns through `subprocess.run` (so `tests/gh_write_guard.py` still sees
   every write).
2. `GhResult`: frozen dataclass with `available: bool`, `returncode: int`, `stdout: str` (raw, callers parse JSON from
   it) and `stderr: str` (passed through `redact_agent_secrets`). Add a small `ok` property
   (`available and returncode == 0`) and a `output` property returning the redacted `stdout + "\n" + stderr` stripped
   (used where today's code returns combined output).
3. `GitHubAdapter.__init__(repo_dir, proxy_env=None, *, run=None, which=None)`: store the values. Private `_runner()`
   returns the injected `run` or `subprocess.run` looked up at call time; private `_which()` likewise for
   `shutil.which`. This is what keeps global `patch("subprocess.run")` / `patch("shutil.which")` in the rest of the
   suite effective.
4. Property `available`: `bool(self._which()("gh"))`.
5. Private `_gh(args, timeout, *, proxy=True)`: if not available return `GhResult(False, 127, "", "gh not found")`;
   build env `{**os.environ, **(proxy_env or {} when proxy), "DOCKER_CLI_HINTS": "false"}`; call
   `run(["gh", *args], cwd=repo_dir, capture_output=True, text=True, check=False, timeout=timeout, env=env)`; convert
   `OSError` and `subprocess.TimeoutExpired` to a 127 result with redacted message. Other exceptions propagate (the
   orchestrators already catch broad exceptions and map them to their error outcomes; keep that behaviour).
6. Methods, each a thin argv builder over `_gh`, with timeouts copied from today's call sites:
   - `pr_view_number(branch)`: `pr view <branch> --json number,title`, timeout 60; returns `GhResult`.
   - `open_or_update(branch, base, title, body)`: calls `pr_view_number`; when ok and stdout non-empty and JSON parses,
     runs `pr edit <branch>` with `--title`/`--body` only when non-empty and returns `("edit", pr_number, result)`;
     otherwise
     `pr create --base <base> --head <branch> --title <title or branch> --body <body or "Automated PR for branch <branch>">`
     and returns `("create", number parsed from /pull/(\d+) in the output, result)`. Keep the decision of the return
     dict shape in `pr.py` so the adapter stays a transport.
   - `ci_checks(target, timeout)`: `pr checks <target> --json bucket,name,state,event,workflow,link`.
   - `mergeability(branch)`: `pr view <branch> --json number,mergeable,mergeStateStatus,statusCheckRollup`, timeout 60
     (one read; the retry loop stays in `pr.py`).
   - `post_review(target, flag, body)`: `pr review <target> <flag> --body <body>`, timeout 60.
   - `post_comment(target, body)`: `pr comment <target> --body <body>`, timeout 60.
   - Merge primitives: `gh(args, cwd=None)` returning a `subprocess.CompletedProcess` exactly like `merge.run_gh` (no
     proxy env, timeout 120, `cwd` defaults to `repo_dir`, missing binary or timeout becomes returncode 127 with

     `pr merge <n> <flag> --match-head-commit <sha>` (and refusing any flag other than `--merge`/`--squash` by raising
