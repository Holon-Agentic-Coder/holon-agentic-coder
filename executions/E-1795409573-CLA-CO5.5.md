# Execution Record: E-1795409573-CLA-CO5.5

## Summary

Implements plan `P-1795409242-CLA-CO5.5` for intent `I-1795409225-remove-token-reduction-copy`: holon-coherence becomes
the only owner of token reduction. `sandbox_executor/token_reduction/` is deleted together with its tests, the A/B
script and three docs. Root CA generation (`launcher/root_ca.py`, `launcher/root_ca_openssl.py`) and the readiness probe
(`launcher/proxy_readiness.py`) now live in the launcher package, and every name `sandbox_executor.cli` exported is
still exported. The `--token-reduce` sidecar runs the holon-coherence image (`launcher/proxy_image.py`) with its own
`start` entrypoint and addon; no addon or source tree is mounted, and the dashboard password reaches the container only
through the spawn environment. The launcher tests moved to `tests/test_launcher_*.py` with no KEEP test lost. Full
suite, `task lint` and the touched Markdown pass. `task lint-docs` still fails, but only on 37 files this branch does
not touch (36 historical `plans/` records and `holon-config/metrics/README.md`).
