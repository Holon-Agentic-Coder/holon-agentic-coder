## Plan Description & Strategy

We will add a single fast, hermetic, AST-based package import-cycle ratchet test module at
`apps/sandbox-executor/tests/test_import_cycle_ratchet.py`.

1. **Subpackage discovery:** Dynamically discover all top-level subpackages under
   `apps/sandbox-executor/src/sandbox_executor/` (direct subdirectories containing `__init__.py`, currently
   `calibration`, `cli`, `entrypoint`, `flow`, `knowledge`, `launcher`, `ledger`, `runners`) so future subpackages are
   included automatically.
2. **AST edge collection:** Walk every `.py` file inside each discovered subpackage (excluding `__pycache__`), parse
   with `ast.parse`, and traverse all AST nodes (`ast.walk`) to capture module-level, conditional, and function-local
   `ast.Import` and `ast.ImportFrom` statements. Resolve relative imports against the importing file's owning package
   (`__init__.py` resolves against its own directory package). Map each resolved target to its top-level subpackage
   under `sandbox_executor`, ignoring self-edges (`src == dst`) and imports outside the discovered subpackage set. Count
   unique `(relative_source_path, line_number, target_subpackage)` import sites per directed `(src_pkg, dst_pkg)` pair
   so each distinct cross-subpackage import statement increments the edge count once.
3. **SCC-based cycle extraction:** Compute Strongly Connected Components of size at least 2 on the directed subpackage
   graph (using Tarjan's algorithm or mutual-reachability closure over the small node set). Every directed edge
   `(src_pkg, dst_pkg)` whose endpoints lie in the same multi-node SCC is a cycle edge with its measured count.
4. **Ratchet evaluation:** Lock the live repository's measured cycle edge counts in a constant mapping
   `BASELINE_CYCLE_EDGE_COUNTS`. Fail if any cycle edge is absent from the baseline (new cycle or newly added cycle
   direction) or has a count strictly greater than baseline; pass cleanly when every cycle edge is at or below baseline
   (including when an edge drops to zero or a cycle is eliminated).
5. **Synthetic verification:** Include unit tests exercising pure-graph cycle/ratchet evaluation and `tmp_path`
   synthetic package trees to prove new 2-cycles, new 3-cycles, edge increases, equal counts, edge reductions, cycle
   removal, and relative/function-local imports all behave as required.

### Implementation Details (No code blocks, only logic/steps)

1. Create `apps/sandbox-executor/tests/test_import_cycle_ratchet.py` with `from __future__ import annotations`, standard
   library imports (`ast`, `collections`, `pathlib.Path`), and `pytest`. Write zero docstrings and zero explanatory
   comments (only `# why:` comments if a non-obvious constraint must be recorded).
2. Implement small, strictly typed helper functions keeping every function within ruff complexity limits (`C901 <= 10`,
   `PLR0912 <= 12`, `PLR0913 <= 5`, `PLR0915 <= 50`):
   - `discover_top_level_subpackages(package_dir: Path) -> frozenset[str]`: return names of direct child directories of
     `package_dir` that contain `__init__.py` and are not `__pycache__`.
   - `owning_package_name(py_file: Path, src_dir: Path) -> str`: return the dotted package name against which relative
     imports in `py_file` resolve (its parent directory relative to `src_dir`).
   - `resolve_import_from(node: ast.ImportFrom, package: str) -> str`: resolve `node.level` against `package` and join
     with `node.module` if present.
   - `extract_imported_targets(source: str, package: str) -> list[tuple[int, str]]`: parse `source` with `ast.parse` and
     walk all AST nodes (`ast.walk`), emitting `(lineno, alias.name)` for `ast.Import` and both `(lineno, base)` and
     `(lineno, f"{base}.{alias.name}")` (skipping wildcard `*`) for `ast.ImportFrom`.
   - `target_subpackage(target: str, root_package: str, subpackages: frozenset[str]) -> str | None`: if `target` starts
     with `f"{root_package}."`, extract the first segment after `root_package` and return it when present in
     `subpackages`, else `None`.
   - `collect_subpackage_import_sites(package_dir: Path, root_package: str = "sandbox_executor") -> dict[tuple[str, str], list[str]]`:
     scan every `.py` file under each discovered subpackage (excluding `__pycache__`), resolve all cross-subpackage
     imports where `source_pkg != target_pkg`, deduplicate per `(relative_path, lineno, target_pkg)` so one multi-symbol
     import line counts as one edge while distinct import statements increment the count, and return sorted site strings
     `f"{rel_path}:{lineno} -> {target_pkg}"` keyed by `(source_pkg, target_pkg)`.
   - `strongly_connected_components(edges: dict[tuple[str, str], int]) -> list[frozenset[str]]`: compute SCCs using an
     iterative or clean Tarjan/Kosaraju implementation (or reachability per node) and return components with size at
     least 2.
   - `cycle_edge_counts(edge_counts: dict[tuple[str, str], int]) -> dict[tuple[str, str], int]`: filter `edge_counts` to
     positive-count edges whose source and target belong to the same multi-node SCC.
   - `ratchet_violations(actual: dict[tuple[str, str], int], baseline: dict[tuple[str, str], int]) -> list[str]`: for
     each `(src, dst), count` in `sorted(actual.items())`, append a clear violation message if `(src, dst)` is not in
     `baseline` (new cycle edge) or `count > baseline[(src, dst)]` (cycle edge count increased). Edges equal to or below
     baseline, or removed entirely, produce no violations.
3. Define `BASELINE_CYCLE_EDGE_COUNTS: dict[tuple[str, str], int]` containing the exact cycle edge counts measured on
   the live `apps/sandbox-executor/src/sandbox_executor/` tree, sorted deterministically by `(src, dst)`.
4. Add the live repository ratchet test `test_sandbox_executor_package_import_cycle_ratchet`:
   - Collect live import sites and counts from `PACKAGE_DIR`.
   - Assert discovered subpackages is non-empty (guarding against accidental path drift).
   - Compute `actual = cycle_edge_counts(counts)` and
     `violations = ratchet_violations(actual, BASELINE_CYCLE_EDGE_COUNTS)`.
   - Assert `violations == []` with a failure message that includes each violation and the offending
     `file:line -> target` import sites.
5. Add synthetic unit tests covering both pure graphs and `tmp_path` package trees:
   - Acyclic synthetic graph yields empty `cycle_edge_counts` and zero violations against an empty baseline.
   - New 2-node cycle fails `ratchet_violations`.
   - New 3-node cycle (`a -> b -> c -> a`) fails `ratchet_violations`.
   - Existing cycle with an increased edge count fails `ratchet_violations`.
   - Existing cycle with equal edge counts passes cleanly.
   - Existing cycle with reduced edge count passes cleanly.
   - Breaking an existing cycle completely (removing the return edge so no multi-node SCC remains) passes cleanly.
   - Synthetic `tmp_path` package tree test verifying AST scanning detects absolute imports, function-local imports,
     `from pkg import subpkg`, and relative imports (`from ..beta import x`), ignores self-imports and root-level
     modules, fails when a new cross-subpackage cycle edge is added, and passes when an edge is removed.
