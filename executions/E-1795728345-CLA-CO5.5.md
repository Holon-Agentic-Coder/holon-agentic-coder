### Step 1: Scope the review identity to a per-call environment copy in source

- `flow/review/git_identity.py`: replaced `_apply_review_git_identity` and the `_review_git_identity` context manager
  with the pure `review_git_env(environ)`, which returns `{**environ, **REVIEW_GIT_ENV}` as a new dict; module docstring
  rewritten. `REVIEW_GIT_ENV` unchanged.
- `entrypoint/review_loop.py`: `main()` calls `_run_main()` directly (no `os.environ` overlay); the resolver's single
  `git commit` in `_commit_resolution` now passes `env=review_git_env(os.environ)`; module docstring bullet updated.

### Step 2: Rewrite tests/test_review_loop_git_identity.py for the scoped identity

- Kept `test_main_runs_no_git_config_user_write_in_any_scope` and `test_review_loop_source_names_no_user_config_key`.
- Replaced the context-manager tests with two `review_git_env` unit tests (overlay on a copy, input never mutated, an
  existing `GIT_AUTHOR_NAME` overridden only in the copy).
- `test_main_leaves_no_identity_in_the_environment_of_any_command`: records `GIT_AUTHOR_*` / `GIT_COMMITTER_*` keys of
  `os.environ` and of any `env=` argument at every `run_cmd` call during `main()`; all records empty.
- `test_child_process_launched_during_main_sees_no_identity`: the fake `run_cmd` launches a real child Python process
  through the real `review_loop.run_cmd` at its first call during `main()`; the child prints `[]`, and the test asserts
  the child actually ran.
- Hermetic commit tests drive the real `_commit_resolution` on the `identityless_repo` fixture (now with a base commit
  whose identity is passed per call): the `user.useConfigOnly` control refuses, the resolver commit is authored and
  committed as `Holon Review Loop Agent`, `os.environ` holds no identity afterwards, and local and global config hold no
  user section.
- `test_only_the_resolver_git_commit_carries_the_identity`: only the `git commit` call carries `REVIEW_GIT_ENV`;
  `git add`, `git status` and `git rev-parse` receive `env=None`.
- Counter-check: with `main()` temporarily overlaying `os.environ` and the commit `env=` removed (not committed), the
  five behavioural tests fail (`5 failed, 4 passed`); the source was restored with `git checkout`.
