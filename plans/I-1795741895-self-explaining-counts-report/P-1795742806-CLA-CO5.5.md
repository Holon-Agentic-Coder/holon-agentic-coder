plus an undeclared edit to `generate.py`. The highest-EV response is to replay the same design with an honest touch set
rather than decompose. Decomposing would multiply pipeline cost for work that fits well inside the 15.0 budget. Steps
are sequential. Entropy and cost are sums: `entropy = 1.4 + 1.6 + 1.6 + 1.0 + 0.8 = 6.4` and
`cost = 3.0 + 3.5 + 3.5 + 2.5 + 1.5 = 14.0`. Overall `p_success` is set by judgement at 0.86. That is just below the
bottleneck Step 3 (0.88), because the step risks are strongly correlated (same design, already proven once), so they do
not multiply. Impact is 62, from the intent's measurement value: both report surfaces plus the removed-line API.
`EV = 0.86 * 62.0 + 0.5 * 3.0 - 0.3 * 6.4 - 14.0 = 53.32 + 1.50 - 1.92 - 14.0 = 38.90`.
