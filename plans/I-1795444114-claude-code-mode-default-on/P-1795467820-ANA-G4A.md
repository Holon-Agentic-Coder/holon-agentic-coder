     environment keys survive; otherwise start with an empty dictionary when code mode is enabled.

     operator's `env` dictionary, set `env["CLAUDE_CODE_EXPERIMENTAL_CODE_MODE"] = "1"` and attach `"env"` to the merged
     settings dictionary.
   - If `claude_code_mode_enabled()` is `False`: do not inject `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE`. If the operator's

     file via `_private_temp_file` so secret values in the file never appear in argv.
