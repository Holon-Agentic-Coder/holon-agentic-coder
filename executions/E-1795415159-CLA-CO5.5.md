How it was done:

- Shared helpers: `_LoopStubs` and `_green_loop_patches` build a `FakeGitHub` from the same `merge`/`ci` inputs (via the
  new `view_for`/`checks_for` converters and `standing_view`), expose it as `stubs.github` (with `stubs.posts()`), and
  inject it by patching the single constructor `flow.review.loop.GitHubAdapter`, so the many call sites under the
  helpers stay unchanged. `_review_loop_gh_stubs` patches the stage and loop constructors and yields the fake. Direct
  loop tests pass `github=FakeGitHub(...)`; stage tests patch `flow.stages.review.GitHubAdapter`.
- `patch("shutil.which", return_value=None)` stays wherever it fences the out-of-scope `gh` callers (`review_target.py`,
  timing lookups), because a real `gh` is on `PATH` in this container.
- Assertions on post mocks became assertions on `post_review` calls (flag and body); "not called" became absence from
  `fake.methods()`; probe call counts became `ci_checks` call counts. CI-registration waits that only ran because the
  fake reports `gh` available are disabled with `ci_registration_timeout=0`, or the CI sequence repeats its first state
  once.
- MISSING_REF scenarios use the real local fallback over a `git init` repository without the branch (no `UNKNOWN` views,
  so no 2-second retries).
