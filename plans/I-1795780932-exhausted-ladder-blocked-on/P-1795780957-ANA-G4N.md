## Plan Description & Strategy

Extend the test-failure diagnosis and escalation loop so that whenever the model tier ladder is exhausted or an
environment/pre-existing/unresolved failure blocks progress, the outcome parks cleanly with a structured,
watcher-consumable parked record. First, add deterministic `blocked_on` attribution (explicit `blocker_map` lookup,

register it in `lazy_exports_review.py`. Third, add hermetic unit tests in `test_test_failure_loop.py` covering all four
required scenarios (including single-run KB non-promotion via `promote_repeated_failure_signatures`). Finally, run
targeted pytest, the full unit test suite, and `uv run task lint` in the foreground.
