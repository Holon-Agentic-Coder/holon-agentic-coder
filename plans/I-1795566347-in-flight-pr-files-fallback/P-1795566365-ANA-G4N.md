## Plan Description & Strategy

Stage 3 admission currently calls `gh pr diff <number> --color never` in
`apps/sandbox-executor/src/sandbox_executor/flow/in_flight.py` for every open flow pull request. When any open PR
exceeds GitHub's 300-file or 20,000-line diff limit, GitHub returns HTTP 406 (`PullRequest.diff too_large`), causing
`open_flow_pull_requests` to return `AdmissionUnavailable` and blocking Stage 3 admission for every flow in the
repository.

1. Introduce `apps/sandbox-executor/src/sandbox_executor/flow/pr_changed_files.py` owning PR changed-file discovery:

   `gh api --paginate --slurp repos/{owner}/{repo}/pulls/{number}/files`, strictly validating the paginated JSON
   response, extracting both `filename` and `previous_filename`, and applying identical `normalise_touch_path` +
   order-preserving deduplication + `is_metadata_path` filtering to both paths.
2. Update `apps/sandbox-executor/src/sandbox_executor/flow/in_flight.py` to delegate PR changed-file retrieval to
   `pr_changed_files.py`, preserving all public APIs and staying well within its 233-line budget.
3. Add comprehensive hermetic unit and admission-overlap tests in `apps/sandbox-executor/tests/flow/test_in_flight.py`,
   then run targeted pytest, `uv run task test`, `uv run python scripts/check_module_budgets.py`, and `uv run task lint`
   in the foreground.

1. Create `apps/sandbox-executor/src/sandbox_executor/flow/pr_changed_files.py` with a clear module docstring, strict
   type annotations, and no imports from `in_flight.py` (preventing circular imports):
   - Define a helper `_normalise_changed_paths(raw_paths)` that maps each raw path through `normalise_touch_path`,
     filters out empty strings and paths where `is_metadata_path(path)` is true, deduplicates preserving first-seen
     order via `dict.fromkeys`, and returns `tuple[str, ...]`.
   - Define a helper `_format_command_failure(command, result)` that redacts `(result.stderr or "").strip()` with
     `redact_agent_secrets`, truncates to 300 characters, and returns `f"'{command}' failed: {detail or 'no output'}"`.
   - Define `_is_diff_too_large(result)` inspecting `(result.stderr or "")` (and `(result.stdout or "")` if stderr is
     empty) case-insensitively, returning `True` only when `"http 406"` or `"too_large"` is present. Non-406 errors
     (e.g., HTTP 500/502/404/403, network failures, or incidental `"406"` in a PR number without
     `"http 406"`/`"too_large"`) return `False`.
   - Define `_extract_entry_paths(entry)` validating that `entry` is a `dict`, `entry.get("filename")` is a non-empty
     `str`, and `entry.get("previous_filename")` (when present and not `None`) is a `str`. On invalid shape, return an
     error string; otherwise return the list of raw paths (`filename` and, if non-empty, `previous_filename`).
   - Define `_parse_slurped_pr_files(stdout, command)` that parses `json.loads(stdout)` (failing closed on
     empty/whitespace-only stdout or `json.JSONDecodeError`), verifies the top-level value is a `list`, verifies every
     element (page) in the top-level list is a `list`, validates and extracts paths from every entry in each page using
     `_extract_entry_paths`, and returns `_normalise_changed_paths(raw_paths)` or an error string on any structural
     mismatch.
   - Define `_pull_request_files_via_api(run_gh, number, repo_dir)` that invokes
     `run_gh(["api", "--paginate", "--slurp", f"repos/{{owner}}/{{repo}}/pulls/{number}/files"], repo_dir)`, returns
     `_format_command_failure(...)` on non-zero exit, and otherwise returns
     `_parse_slurped_pr_files(result.stdout or "", ...)`.
   - Define public function
     `pull_request_changed_files(run_gh: merge.GhRunner, number: int, repo_dir: str) -> tuple[str, ...] | str`:
     - Calls `run_gh(["pr", "diff", str(number), "--color", "never"], repo_dir)`.
     - On `returncode == 0`, returns `_normalise_changed_paths(patch_paths(result.stdout or ""))`.
     - On non-zero exit with `_is_diff_too_large(result)` true, delegates to
       `_pull_request_files_via_api(run_gh, number, repo_dir)`.
     - On any other non-zero exit, returns `_format_command_failure(f"gh pr diff {number}", result)`.
   - Keep every function small and readable, well within ruff limits (`C901 <= 10`, `PLR0912 <= 12`, `PLR0913 <= 5`,
     `PLR0915 <= 50`), and keep the file well under 200 lines.
2. Update `apps/sandbox-executor/src/sandbox_executor/flow/in_flight.py`:
