## Plan Description & Strategy

Add one rule to each of the two shipped prompt templates and one focused test module that pins both the rule and the
templates' placeholders.

- The planner rule is a new bold-headed block, `**Environment Overlay Discipline:**`, placed directly after the
  `**Test-Run Discipline:**` block and before the "You will be eliminated" list, outside the fenced plan format. It
  says: a diff that sets, overlays or removes environment variables, cwd or git config for a process that spawns
  children must list the child processes affected and carry a test that runs one of them under the new environment; the
  plan lists those child processes and names that test in the step that makes the change.
- The reviewer rule is item 13 of `## Reviewer turn contract`, after the self-explaining item 12. It says: a diff that
  sets, overlays or removes environment variables, cwd or git config for a process that spawns children must list the
  child processes affected and carry a test that runs one of them under the new environment; report a missing list or a
  missing test as an Important finding, which blocks approval.
- The test module `apps/sandbox-executor/tests/test_prompt_environment_rule.py` reads both real files, asserts the
  shared rule phrases plus the per-prompt consequence phrase, and renders both templates through the real renderers to
  check that every placeholder that rendered before still renders.
